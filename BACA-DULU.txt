============================================================
  SANTARA — Setia Antar Tanpa Ragu
  Aplikasi antar-jemput siswa (rumah → tempat les)
============================================================

CARA MENJALANKAN (3 langkah)
------------------------------------------------------------
1. Install Node.js 18 atau baru → https://nodejs.org (pilih LTS)
   (Windows: jalankan file installer, klik Next sampai selesai)

2. Buka folder hasil ekstrak ini, lalu:
   - Windows : klik dua kali  mulai-windows.bat
   - Linux/Mac: buka Terminal di folder ini, ketik:  bash mulai.sh
   - Atau manual di Terminal/CMD:   node server.js

3. Buka browser:
   - Di komputer ini  : http://localhost:3000
   - Dari HP (Wi-Fi yang sama): http://192.168.x.x:3000
     (alamat IP komputer Anda tampil di jendela hitam saat server jalan)

Buka di dua HP/jendela berbeda: satu sebagai SISWA, satu sebagai
PENJEMPUT — keduanya terhubung online secara realtime.

============================================================
  HAL PENTING
============================================================
* GANTI LOGO  : timpa file  public\assets\logo.png  dengan logo Anda.
* TARIF       : ubah di aplikasi, menu Akun → Pengaturan tarif & peta.
                Bawaan: Rp 6.000 (2 km pertama) + Rp 3.500/km,
                minimum Rp 8.000, dibulatkan ke Rp 500.
* GOOGLE MAPS : tanpa API key pun aplikasi tetap online (OpenStreetMap).
                Punya key? Tempel di Akun → Pengaturan tarif & peta.
* PASANG DI HP: Android (Chrome) menu ⋮ → "Install aplikasi".
                iPhone (Safari) tombol Bagikan → "Tambah ke Layar Utama".
* DATA        : tersimpan otomatis di  data\db.json .
                Hapus file itu untuk mengembalikan data contoh.

Panduan lengkap ada di file README.md.
Selamat menggunakan — Setia Antar Tanpa Ragu!
